# 图标规范与来源

## 为什么重做

前几版图标是手写贝塞尔曲线拼出来的（圆角环、虚线选框、斜箭头都是目测坐标），
在 36px 下会显出"线条歪、不够规范"。原因不是审美，而是**缺少网格**：没有统一的 grid、stroke、端点规则，
每条曲线的控制点都是临时算的。

## DSH 生态的做法（2026-11-07 调研）

**声明方式**（`package.json` 顶层字段，DSH 插件列表据此渲染）：

```json
{ "icon": "./icon.svg" }
```

同类插件的常见做法（按公开形态归纳，不点名具体插件）：

| 插件 | 图标文件 | viewBox | 风格 |
|---|---|---|---|
| 美术类插件 | `./icon.svg` | 0 0 256 256（Phosphor 网格） | 单色实心字形 + 渐变填充 + 半透明副本错位做投影层次 |
| 上下文类插件 | `icon.svg` | 0 0 1024 1024 | 多色实心几何块，无渐变 |
| 运维类插件 | `./docs/assets/icon.png` | — | 位图（少见） |
| 本插件 | `./icon.svg` | **0 0 24 24**（Tabler 网格） | 描边字形 + 渐变描边 |

共同点：

1. **都不画底板**——容器由 DSH 提供（36px 圆角白块），图标只画字形；
2. **都用现成图标库的网格**（Phosphor 256 / Tabler 24），不是手写坐标；
3. `width`/`height` 写 **30**（与容器 36px 匹配），`viewBox` 决定笔画倍数；
4. 颜色走品牌渐变，明暗层次靠**透明度**而不是第二套色。

## 本插件的网格

- 网格：**24 × 24**，描边 **1.7**（比图标库默认 2 细一档），`stroke-linecap/linejoin: round`
- 字形占 3–22 区间（约 80%），比参考插件 artkit 在容器里的占比略大
- 几何取自 **Tabler `photo-up`**：画框 + 远山 + 折线 + 向上箭头
- 自绘元素（补齐细节）：左上太阳点、右上主火花、角落小火花
- 描边与火花共用一条渐变 `#38BDF8 → #5B5BF0`（对角 3,3 → 21,21）

## 改法

```svg
<!-- 改粗细：stroke-width（1.7 = 当前；2 = 图标库默认，更粗） -->
<g stroke="url(#ik-g)" stroke-width="1.7" stroke-linecap="round" stroke-linejoin="round" fill="none">

<!-- 改颜色：两个 stop -->
<stop offset="0" stop-color="#38BDF8"/><stop offset="1" stop-color="#5B5BF0"/>

<!-- 改火花：主火花中心 14.4,7.8 半径 2.0；小火花中心 18.2,4.9 半径 0.8；太阳点 6.6,7.3 半径 1.15 -->
```

## 换图形

`icon`（取 24 网格路径）→ 复制 `<path d="…">` 覆盖对应行 → 保持 `stroke-width="2"` 不变。
若新图形自带面板色块，先拆成纯描边再拼，避免与本插件的线性语言冲突。

## 细节清单（2026-11-07 补充）

| 元素 | 坐标 | 语义 |
|---|---|---|
| 画框（右下开口） | 3,3 → 21,15.5 | 图片 |
| 远山 | (3,16)→(8,11)→(11.5,14.5) | 画面内容 |
| 右坡折线 | (14,14)→(19.2,12.5) | 画面内容延伸 |
| 太阳点 | (6.6,7.3) r1.15 实心 | 照片 |
| 主火花 | (14.4,7.8) r2.0 实心 | AI 生成 |
| 小火花 | (18.2,4.9) r0.8 实心 | AI 生成（成组，大尺寸可见） |
| 向上箭头 | (19,22)→(19,16) + 箭头 | 放大 |

36px 下小火花会糊掉、太阳点与主火花仍清楚——这是刻意的渐变降级（大尺寸看细节，小尺寸看轮廓）。
