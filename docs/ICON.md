# 图标规范

## 声明方式

插件图标在 `package.json` 顶层声明，DSH 插件列表据此渲染：

```json
{ "icon": "./icon.svg" }
```

DSH 会为图标提供 36px 圆角白色容器。`icon.svg` 的 `width` 与 `height` 为 30，`viewBox` 决定笔画倍率；图标本身不绘制底板。

## 网格与字形

- 网格：24 × 24。
- 描边：1.7，比图标库默认值 2 细一档；`stroke-linecap` 与 `stroke-linejoin` 均为 `round`。
- 字形范围：3–22，约占画布 80%。
- 几何来源：Tabler Icons 的 `photo-up`，包含画框、远山、折线与向上箭头。
- 自绘元素：左上太阳点、右上主火花与角落小火花。
- 渐变：描边与火花共用 `#38BDF8 → #5B5BF0`，方向为 (3,3) 至 (21,21)。

## 修改方式

```svg
<!-- 描边粗细 -->
<g stroke="url(#ik-g)" stroke-width="1.7" stroke-linecap="round" stroke-linejoin="round" fill="none">

<!-- 渐变颜色 -->
<stop offset="0" stop-color="#38BDF8"/><stop offset="1" stop-color="#5B5BF0"/>

<!-- 火花坐标：主火花中心 14.4,7.8，半径 2.0；小火花中心 18.2,4.9，半径 0.8；太阳点 6.6,7.3，半径 1.15 -->
```

替换图形时，从 24 网格图标库获取路径，复制 `<path d="…">` 覆盖对应行，并保持 `stroke-width="1.7"`。若新图形自带面板色块，应先拆分为纯描边，以保持与当前线性图标一致。

## 元素清单

| 元素 | 坐标 | 含义 |
|---|---|---|
| 画框（右下开口） | 3,3 → 21,15.5 | 图片 |
| 远山 | (3,16) → (8,11) → (11.5,14.5) | 画面内容 |
| 右坡折线 | (14,14) → (19.2,12.5) | 画面内容延伸 |
| 太阳点 | (6.6,7.3)，半径 1.15，实心 | 照片 |
| 主火花 | (14.4,7.8)，半径 2.0，实心 | AI 生成 |
| 小火花 | (18.2,4.9)，半径 0.8，实心 | AI 生成（成组，大尺寸可见） |
| 向上箭头 | (19,22) → (19,16) 加箭头 | 放大 |

在 36px 尺寸下，小火花会弱化，太阳点与主火花仍保持可辨识。这是有意的降级：大尺寸保留细节，小尺寸优先轮廓。
